# VeriFlow UI

You are a Senior Product Designer, Frontend Architect, and React UI Engineer.



Your responsibility is to design and generate ONLY the frontend of a modern SaaS application.



DO NOT implement backend logic.

DO NOT create APIs.

DO NOT generate database code.

DO NOT generate authentication logic.

DO NOT simulate backend services.



The frontend will later connect to a production Node.js + Express backend.



--------------------------------------------------



PROJECT



AI-Assisted Academic Certificate Verification Portal



This is a Master's-level software engineering project.



The design language should be inspired by:



• Notion

• Linear

• Stripe Dashboard

• GitHub

• Apple Human Interface Guidelines



The interface must feel:



• Modern

• Minimal

• Professional

• Spacious

• Elegant

• Enterprise-grade

• Trustworthy

• Mobile-first

• Accessibility-friendly



Avoid:



• Heavy gradients

• Bright colors

• Glassmorphism

• Cluttered dashboards

• Oversized cards

• Flashy animations

• AI-generated dashboard appearance



--------------------------------------------------



TECH STACK



• React

• Vite

• Tailwind CSS



Use reusable components throughout.

--------------------------------------------------



NO DEMO DATA / NO MOCK BACKEND



Do NOT generate demo data.



Do NOT generate fake users.



Do NOT generate fake institutions.



Do NOT generate fake graduates.



Do NOT generate fake certificates.



Do NOT generate fake statistics.



Do NOT generate fake charts.



Do NOT generate sample JSON.



Do NOT generate placeholder business records.



Do NOT hardcode numbers into dashboard cards.



Do NOT simulate backend responses.



Do NOT create mock APIs.



Do NOT create fake authentication.



Instead:



• Build reusable UI components.



• Build forms only.



• Build empty tables with headers.



• Build cards that expect future API data.



• Use Loading Skeletons.



• Use Empty States.
